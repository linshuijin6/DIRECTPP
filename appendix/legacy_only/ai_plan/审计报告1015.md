## (B) 已证实的科学与代码实现问题 (精确位置定位)

### 1. 结构性代码缺陷：三折交叉验证 DataLoader 作用域未更新 `[VERIFIED]`
- **精确位置**：[`3_classification/mri2pet all data- classification-densenet.ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/3_classification/mri2pet%20all%20data-%20classification-densenet.ipynb) Cell 6, Cell 8, Cell 11
- **具体事实**：
  1. 在 Cell 6 中，执行 `for fold_idx, (train_indices, val_indices) in enumerate(skf.split(all_samples, labels)):` 循环，但循环体内仅对变量 `train_data` 和 `val_data` 进行赋值。循环结束时，这两个变量**停留在最后一折 (Fold 3)**。
  2. 在 Cell 8 中，使用留在内存中的 `train_data` 和 `val_data` 构建了唯一的全局 `train_loader` 与 `val_loader`。
  3. 在 Cell 11 中，正式开始训练循环 `for fold_idx, (train_indices, val_indices) in enumerate(kf.split(all_samples)):`，但在每个 fold 内部：
     ```python
     for epoch in range(max_epochs):
       for batch_data in train_loader:  # 始终使用 Cell 8 中未被切分的全局 Loader!
         ...
       for val_data in val_loader:  # 验证集也始终是同一个 DataLoader!
         ...
     ```
     `train_indices` 和 `val_indices` 彻底被丢弃，未用于重建当前折的 Dataset/DataLoader。
- **科学后果**：Fold 1、Fold 2、Fold 3 实际上在完全相同的数据划分上运行了 3 遍，**未发生真正的三折交叉切分验证**。

### 2. 统计指标计算缺陷：全 Epoch 验证性能算术平均 `[VERIFIED]`
- **精确位置**：[`3_classification/mri2pet all data- classification-densenet.ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/3_classification/mri2pet%20all%20data-%20classification-densenet.ipynb) Cell 11 末尾
- **具体事实**：
  代码在计算最终输出指标时采用：
  ```python
  mean_accuracy = np.mean([np.mean(acc) for acc in all_accuracy_values])
  mean_auc = np.mean([np.mean(auc) for auc in all_auc_values])
  ```
  `all_accuracy_values` 记录了模型从 Epoch 2 至 Epoch 200 共 100 次验证的每轮数值。该语句将“未收敛的初始轮次（如 Epoch 2, 4）”与“已收敛轮次”混合求平均，或在部分分支中直接取最后几轮均值，而非各折最优 Checkpoint 的测试集独立评估。

### 3. 人口学检验严重伪造漏洞：Table 1 方差分析使用伪随机数生成 `[VERIFIED]`
- **精确位置**：[`4_analysis_and_figures/scripts/paper data statistics 2.ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/4_analysis_and_figures/scripts/paper%20data%20statistics%202.ipynb) Cell 4
- **具体事实**：
  ```python
  np.random.seed(42)
  # 各组样本数量
  n_AD, n_CN, n_EMCI, n_LMCI, n_MCI = 317, 577, 291, 152, 520
  # 年龄 (Age)
  age_AD = np.random.normal(74.90, 7.99, n_AD)
  age_CN = np.random.normal(72.55, 6.65, n_CN)
  ...
  p_age = f_oneway(age_AD, age_CN, age_EMCI, age_LMCI, age_MCI).pvalue
  p_mmse = f_oneway(mmse_AD, mmse_CN, mmse_EMCI, mmse_LMCI, mmse_MCI).pvalue
  ```
  作者为了填补 Table 1 人口学统计表中的 $P$ 值，直接使用各组均值和方差，通过 `np.random.normal` 采样生成伪受试者并计算 ANOVA，**未基于 ADNI 临床真实样本数据做单因素方差检验**。

### 4. 统计检验方法与声称严重背离：独立 t 检验代替配对检验且未做 FDR `[VERIFIED]`
- **精确位置**：
  - 论文正文：明确声称 *"Paired-sample t-tests between synthetic and real images revealed no statistically significant differences... adjusted for multiple ROI comparisons using false discovery rate (FDR)"*。
  - 实际代码：[`4_analysis_and_figures/scripts/paper data statistics .ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/4_analysis_and_figures/scripts/paper%20data%20statistics%20.ipynb) Cell 18 与 [`4_analysis_and_figures/scripts/violin.py`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/4_analysis_and_figures/scripts/violin.py) 第 80–100 行。
- **具体事实**：
  代码实际调用的是：
  ```python
  t_stat, p_value = ttest_ind(real_av45, syn_av45)  # 独立样本 t 检验！
  _, p_real = ttest_ind(cn_real, ad_real, equal_var=False)
  ```
  且全库无任何 `multipletests` 或 FDR 校正函数。
- **科学后果**：对于同一受试者的 Real 与 Syn PET，独立 t 检验将受试者间巨大变异（Inter-subject variability）计入分母误差项，导致统计功效被大幅削弱，**虚假地制造了“无显著差异 ($p>0.05$)”的假象**。一旦换成严格的配对检验 (`ttest_rel`)，微小的系统性合成偏差将暴露。

### 5. 蒸馏机制描述背离：Teacher-Student 蒸馏实为固定步长微调 `[VERIFIED]`
- **精确位置**：[`1_code/notebooks/mri2pet _two trace_new-final.ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/1_code/notebooks/mri2pet%20_two%20trace_new-final.ipynb) Cell 9 (约第 35–45 行)
- **具体事实**：
  论文声称模型使用 Teacher-Student 蒸馏实现了单步快速生成。但代码实现在 Epoch 140 后的处理方式为：
  ```python
  if epoch >= 140:
    time_embedding = torch.tensor([0], device=images.device, dtype=torch.long)
  ```
  实际并没有预训练的 Teacher 连续流轨迹作为引导，亦无特征蒸馏 Loss，而是**直接将时间步截断为 $t=0$ 的端点微调 (Endpoint Fine-tuning)**。

### 6. Equation (1) 与生成器代码脱节：仿射对齐参数被完全旁路 `[VERIFIED]`
- **精确位置**：[`1_code/two GPU run code.py`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/1_code/two%20GPU%20run%20code.py) 第 330–365 行 与 [`2_checkpoints/adapter_vectors/`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/2_checkpoints/adapter_vectors/)
- **具体事实**：
  论文 Equation (1) 声称训练了一个仿射适配器（Affine Adapter，$a \cdot E_{\text{text}} + b$）以 100 权重强制文本与 PET 图像特征对齐至 0.82 相似度。然而在最终执行的生成器训练代码中：
  ```python
  desc_text_features = model.get_text_features(
      text_inputs['input_ids']
  )  # 直接调用原始 BiomedCLIP
  c_mri = text_features[0].unsqueeze(0)
  c_pet = text_features[1].unsqueeze(0)
  ```
  生成器在 Cross-Attention 注入时直接拼接了原始 BiomedCLIP 文本向量，**从未加载过 `adapter_vectors` 中的权重，也没有执行仿射变换**。

## (C) 高风险但未完全证实的问题与科学隐患

### 1. 下游分类评估存在样本内重构泄漏 (In-sample Reconstruction) `[RISK]`
- **风险描述**：
  - 生成模型由 `train_data_with_description.json` 中的 **500 名受试者** 训练收敛（见 `5_data_splits/`）。
  - 下游分类器在 `filtered_subjects_with_description.csv`（共 1,857 名受试者）及其生成的 PET 影像上进行评估。
  - **证据**：经集合比对，生成器训练的 500 名受试者 **100% 包含在分类数据集中**（占分类总集的 26.93%）。
  - **严重后果**：这 500 名受试者的 Syn-PET 是生成器“见过的样本的自重构（In-sample Reconstruction）”，而非真正的**留出折泛化生成（Out-of-Fold, OOF）**。将这批数据混入分类器训练和测试，人为拉高了合成数据在下游任务中的表征能力。

### 2. 临床文本引导导致的“标签直通捷径 (Label Leakage)” `[RISK]`
- **风险描述**：
  - 在 [`5_data_splits/filtered_subjects_with_description.csv`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/5_data_splits/filtered_subjects_with_description.csv) 中，送入 BiomedCLIP 编码的 `Description` 文本明确包含：
    `Global CDR: 0.0 / 0.5`, `MMSE: 30 / 27 / 26`, `FAQ: 0 / 24`, `NPI-Q: 0 / 5` 等字段。
  - **医学常识**：在 ADNI 临床诊断标准中，Global CDR = 0 即定义 CN，0.5 定义 MCI，$\ge 0.5$ 伴 MMSE 下降即定义 AD。
  - **严重后果**：生成模型通过 Cross-Attention 实际上“被明示”了患者是否有痴呆症，进而倾向于根据文本中的认知分数直接“绘制”出萎缩或淀粉样蛋白富集图像，下游分类模型在分类 Syn-PET 时，实际上是在**间接读取文本中的认知评分**。

### 3. 多示踪剂缺失掩膜处理有效性 `[VERIFIED / LOW RISK]`
- **核实结论**：
  在 [`1_code/notebooks/mri2pet _two trace_new-final.ipynb`](file:///mnt/nfsdata/nfsdata/linshuijin/DIRECTPP/1_code/notebooks/mri2pet%20_two%20trace_new-final.ipynb) Cell 9 中已证实：
  ```python
  has_fdg = not torch.all(seg_fdg == 0)
  has_av45 = not torch.all(seg_av45 == 0)
  ```
  缺失的示踪剂对应损失置 0，仅反向传播存在的数据。这一机制在物理上正确且鲁棒。
