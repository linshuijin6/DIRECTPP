修改 1：纠正 3D RF 的消融定位

位置： Methods §4.4，原稿第 318 行，Comparison Methods。

Original

```
\item \textbf{3D Rectified Flow (3D RF)}~\cite{Xing2022}: A flow-based generative model that shares DIReCT$++$’s underlying ODE framework but lacks domain-informed conditioning. This ablation model isolates the contribution of our BiomedCLIP-enhanced guidance module.
```

Revised

```
\item \textbf{3D Rectified Flow (3D RF)}~\cite{Xing2022}: A flow-based generative model that shares DIReCT$++$’s underlying ODE framework but lacks domain-informed conditioning.
```

修改理由： 原稿第一句已经准确说明 3D RF 的模型特点。直接删除第二句缺乏严格控制变量依据的消融结论，即可解决审稿人指出的问题，无须重写已有正确表述。

修改 2：准确界定联合与独立示踪剂生成比较

位置： Methods §4.4，原稿第 320 行，Comparison Methods。

Original

```
\item \textbf{DIReCT (Single-Modality Variant)}~\cite{liu2025direct}: A simplified version of our framework that synthesizes only one PET tracer type (either \textsuperscript{18}F-FDG or \textsuperscript{18}F-AV45) per forward pass. In contrast to DIReCT$++$—which jointly generates both tracers through cross-modality interaction—this variant enables direct assessment of the benefits conferred by multi-tracer synergistic generation in terms of anatomical consistency and quantitative accuracy.
```

Revised

```
\item \textbf{DIReCT (Single-Modality Variant)}~\cite{liu2025direct}: A simplified version of our framework that synthesizes only one PET tracer type (either \textsuperscript{18}F-FDG or \textsuperscript{18}F-AV45) per forward pass. In contrast to DIReCT$++$, which uses a shared network conditioned on the target tracer, this variant employs separately trained single-tracer models.
```

修改理由： 保留已有的单示踪剂定义，仅修正第二句。DIReCT++ 使用共享网络分别生成目标 PET，并非一次前向传播同时输出两种 PET；同时，Full/Single 的比较也不能单独证明多示踪剂协同机制带来的收益。

修改 3：在 G5 中补充临床信息分类基线

位置： Methods §4.4，Diagnosis and Prognostic Stratification，原稿第 342 行。

Original

For each classification task, models were independently trained and evaluated using the following input modalities: (i) real \textsuperscript{18}F-FDG and/or \textsuperscript{18}F-AV45 PET; (ii) Syn-PET counterparts; (iii) structural MRI alone; and (iv) multi-modal combinations, including MRI\,+\,Syn-FDG, MRI\,+\,Syn-AV45, and MRI\,+\,Syn-FDG\,+\,Syn-AV45. All models were optimized on identical training protocols and validated via 3-fold cross-validation with stratified sampling to preserve class distribution across folds. Performance was quantified using accuracy (ACC), sensitivity (SEN), and specificity (SPE).

Revised

For each classification task, image-based models were independently trained and evaluated using the following input modalities: (i) real \textsuperscript{18}F-FDG and/or \textsuperscript{18}F-AV45 PET; (ii) Syn-PET counterparts; (iii) structural MRI alone; and (iv) multi-modal combinations, including MRI\,+\,Syn-FDG, MRI\,+\,Syn-AV45, and MRI\,+\,Syn-FDG\,+\,Syn-AV45. Additional Clinical-only and MRI+Clinical classification baselines were evaluated to assess the diagnostic information available from clinical variables without synthetic PET inputs. The imaging-based models followed a common training protocol, and all configurations were evaluated using subject-level 3-fold cross-validation with stratified sampling to preserve class distribution across folds. Performance was quantified using accuracy (ACC), sensitivity (SEN), specificity (SPE), and area under the receiver operating characteristic curve (AUC).

修改理由： 增加已经完成的 Clinical-only 和 MRI+Clinical 分类对照，并准确区分影像分类器与临床分类器。保留原有模态配置和三折评价设计。AUC 的补充也与原稿 Results 及已完成的 G5 统计评价一致。

注意： 这处与 R2-5、R3-1 等意见共享同一段 Methods。统一实施时应合并修改，不要将不同审稿意见产生的版本依次覆盖。
