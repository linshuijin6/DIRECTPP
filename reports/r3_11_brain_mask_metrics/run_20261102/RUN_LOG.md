This file describes engineering recovery; the supplementary draft tables contain only final aggregate results.

- The initial two-subject precheck covered both folds, both tracers and all three models (12 metric rows). Its E1 CPU versus GPU SSIM differences were zero; direct NumPy errors and independent SSIM erosion checks passed. The separate eight-row cross-node baseline precheck also passed with identical target/mask hashes.
- The first remote precheck reached a mask before the individual-file copy completed and exited with FileNotFoundError. Its logs remain in the remote `pilot/` namespace. The successful precheck is retained as `remote_pilot_results.json` and `remote_pilot_validation.json`. Frozen masks were subsequently packaged without loss; all 1,856 pack/unpack round trips were exact.
- Initial prediction-file copies were stopped when it became possible to evaluate original baseline NIfTIs in place. All partial copies and transfer receipts remain under `inputs/` and `transfer/`; these partial copies are not the source of final remote metrics.
- Full evaluation was resumed and split into four disjoint subject shards to avoid repeated large-file reads. Completed subject records were preserved in `metrics_Full_seed.csv`; initial and pre-resume files were retained. The four shards all exited with code zero, completing 2,961 metric rows at approximately 21:31 on 2026-11-02.
- The first complete merge intentionally stopped at the exact target-array hash gate: 1,401 subject-tracer targets differed between local canonical Full and remote PET caches, while all mask hashes agreed. No paired statistics were generated from that mixed-target dataset. The stop is retained in `collection_failure.txt`, `target_identity_mismatch_initial.csv`, and `target_resolution_status.json`.
- A nearest-reference low-bit transport attempt did not reproduce every full reference hash and was rejected. Its failed log and incomplete transport archives remain under `canonical_targets/`; no approximate reconstruction is accepted as a scientific input.
- Exact transport uses block checksums only to locate bytes requiring transmission; acceptance requires the original reference array SHA-256 and the canonical Full array SHA-256 for every complete array. The original and canonical arrays, caches and NIfTIs are never overwritten. Exact canonical values are restored in memory, and the affected 2,802 baseline metric rows are reevaluated with the same metric function. Initial baseline outputs are retained separately; final assembly requires byte-identical target and mask arrays across all three models for every matched subject-tracer-fold.
- The initial remote completion receipts contain a metadata-only variable-shadowing error: `ssim_source_sha256` contains the row count. The actual SSIM source hash was asserted before computation and independently audited on all four nodes. Original receipts are preserved and their original evaluator source is frozen in `source_snapshots/remote_evaluate_initial.py`. Current code uses distinct names, and canonical recheck receipts record the correct kernel hash. See `ssim_source_audit.json`.

No training, new prediction generation, checkpoint selection, resampling, registration, mask generation, or intensity renormalization is part of this task. No manuscript, formal supplementary, existing statistical report or Notion content is edited. No Git commit or push is performed. The final completion/validation files, rather than the presence of historical failure logs, establish the final analysis status.
