## 2. 方法与完整结果

分别对 Real 和 Syn 计算独立两组样本效应量：

`s_p = sqrt(((N_AD−1) s_AD² + (N_CN−1) s_CN²) / (N_AD+N_CN−2))`

`d = (mean_AD − mean_CN) / s_p`；所有组内 SD 为样本 SD（ddof=1）。`delta_d = d_syn − d_real`；`abs_d_difference = |d_syn| − |d_real|`。这不是 Real−Syn 配对差的 Cohen’s dz。单位为 normalized uptake（任意单位），不称 SUV/SUVR。

## 3. 方向、幅度及原稿表述

C 中 AV45 五项均为 AD>CN，Real d=1.5133–1.6831、Syn d=1.5288–1.6437；D 中 FDG 五项均为 AD<CN，Real d=−1.3972 至 −0.4848、Syn d=−1.3201 至 −0.4308。C/D 十项有九项绝对效应量减小，仅 AV45 左横颞回略增（+0.0156）。全部20项中16项绝对效应量减小、4项增加。

需要明确呈现的差异：

- 最大绝对幅度变化：FDG 右侧峡部扣带回（2010），d −1.397180→−1.320097，|d| 减小0.077082（约5.5%）；左侧峡部扣带回（1010）−1.253072→−1.177431，减小0.075640（约6.0%）。
- FDG 左缘上回（1031）−0.484757→−0.430784，|d| 减小0.053973（约11.1%），为 C/D 十项中相对减幅最大者。这里百分比仅描述幅度变化，没有统计或临床阈值含义。
- **符号改变：**AV45 右海马（E/53）−0.006832→+0.000552；FDG 左丘脑（F/10）−0.009660→+0.058216。两处原始效应均接近零，不能据此认定疾病效应出现可靠反转。
- E 中 AV45 Left/Right-VentralDC（28/60）的 Real/Syn 均 q≥0.05，与图面 ns 一致；原先侧脑室4/43不属于这些图示条目。

**对 precisely preserved 的判断：**指定 CSV 的 C/D 大体保留组间方向及效应量级，但存在上述幅度差异；E/F 还有近零效应的符号改变。没有事先规定的效应量保持容许界值，不能把最大0.0771差值简单判为临床明显或临床可忽略，也不能将相近 d 或显著性保持解释成精确保持。若最终写入回复，证据支持较窄的“组间差异方向大体保持，并报告效应量变化”。本轮不修改原稿。
