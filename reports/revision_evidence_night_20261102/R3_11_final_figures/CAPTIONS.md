# Supplementary figure caption drafts

## FDG

**Supplementary Figure S[FDG]. Representative and lowest-SSIM QC-passed FDG cases from frozen two-fold out-of-fold DIReCT++ predictions.** Columns show (A) the input MRI, (B) real FDG PET, (C) synthetic FDG PET, and (D) voxel-wise absolute error, defined as |synthetic PET − real PET|. From top to bottom, rows show the cases nearest the median and 10th percentile of the saved subject-level SSIM distribution, followed by the case with the lowest saved SSIM among QC-passed cases. Selection used the existing whole-volume SSIM values for DIReCT++ Full at epoch 165 from the original-author reproduction, rather than slice-specific or brain-mask SSIM. All three cases were selected from the same FDG-specific eligible set (n = 1,597), after applying the previously recorded MRI/mask grid QC exclusion; no further exclusions were made based on image appearance. Percentiles used linear interpolation, and ties in distance to the target percentile were resolved by ascending subject identifier. Selection was fixed before loading the case images. Each row contains matched data from one subject and the corresponding held-out fold. The saved SSIM values, rounded to four decimal places, are shown beside each row. All panels show the same central slice index in the frozen MRI-anchored array grid (axis 2, zero-based index 80), using the existing display rotation without additional anatomical reorientation, registration, resampling, or intensity normalization. Real and synthetic PET share a fixed 0–1 normalized-uptake scale (magma); absolute error uses a separate fixed 0–1 scale (inferno), common to all cases. MRI is shown in grayscale with a separate 0–1 intensity scale. No displayed values are clipped. Intensities and errors are in arbitrary normalized units, not SUV or SUVR. Error maps cover the displayed grid and are not restricted to the brain mask. No image-quality metrics were recomputed for this figure. OOF, out-of-fold; QC, quality control; SSIM, structural similarity index measure.

Files: [PNG](R3_11_FDG_cases.png), [PDF](R3_11_FDG_cases.pdf).
